Photo slots for the "Trades we've built for" section on index.html
====================================================================

The homepage has four image tiles already wired up and styled. Right now
they show a soft gradient because no image files exist yet — nothing is
broken, they just fall back gracefully. Drop in real JPG or PNG files
with these exact names and they'll appear automatically, no code changes
needed:

  images/salon.jpg     — hair & beauty salon
  images/trades.jpg    — electrician or plumber at work
  images/cafe.jpg      — café / hospitality
  images/office.jpg    — small office / admin work

Recommended size: roughly 800x1000px (portrait), JPG, under ~300KB each
so the page stays fast to load.

Where to get free, properly licensed photos:

  Pexels          https://www.pexels.com          — free for any use, no attribution required
  Pixabay         https://pixabay.com              — free for any use, no attribution required
  Unsplash        https://unsplash.com             — free for any use, attribution appreciated
  Wikimedia Commons  https://commons.wikimedia.org — genuinely CC-licensed; check each
                     file's license tag, some require attribution

Search each site for the trade you want (e.g. "hair salon interior",
"electrician at work", "coffee shop barista", "small office desk"),
download a photo you like, rename it to match the filenames above, and
place it in this folder.

If you'd rather send me direct links to specific photos you've already
picked, I can wire them in and adjust the crop/positioning for you.
